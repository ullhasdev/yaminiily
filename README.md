# Love.exe website

This is a Vite + React + TypeScript project prepared from the supplied `yaminiiloveyou.tsx`.

## Deploy from a phone

1. Extract this ZIP on your phone.
2. In GitHub, create a new repository.
3. Upload the **contents** of this folder (not the ZIP itself) to the repository. If GitHub's mobile website makes folder upload difficult, use StackBlitz to import the project or upload files individually.
4. In Vercel, import that GitHub repository.
5. Vercel should detect Vite. Use build command `npm run build` and output directory `dist`.
6. Deploy and open the generated URL on your phone to test it.

The project includes the default content embedded in the TSX. The app can also load optional text files from `public/content/` if you add them there.
